# Diagramas UML

En este directorio se guardan los diagramas del sistema:


### Diagramas requeridos:
1. `diagrama_clases_inicial`: Diagrama de clases inicial antes de la aplicacion de patrones SOLID y GRASP.
2. `diagrama_casos_uso`: Diagrama de casos de uso que muestra los actores involucrados y los requisitos funcionales de cada uno.
3. `secuencia_agregar_saldo`: Diagrama de secuencia del caso de uso "Agregar saldo a cuenta".
4. `secuencia_retirar_vehiculo`: Diagrama de secuencia del caso de uso "retirar vehiculos".
5. `diagrama_clases_final`: Diagrama de clases final luego de la aplicacion de patrones SOLID y GRASP.
